主要結論

把 A3 的 attention 輸出 patch 進 A0 會完全重現 A3 的行為；因為決策位置只能透過 attention 讀取前文，這是結構上必然的結果。有資訊量的是 MLP：只 patch MLP 輸出就能把 A0 的 p(call) 降到 0.32，代表 attention 讀進來的差異在決策位置被 MLP 大幅處理。

逐層 residual patching

  • A0 ← A3 residual
  • A3 ← A0 residual

在第 l 層把另一條件的 residual stream patch 進決策位置。第 0–20 層的 patch 會被後面的層重新讀取前文覆蓋，幾乎不改變決策；p(call) 在第 21–29 層快速移動，約在第 24 層越過 0.5，第 29 層後達到另一條件的水準。這個區間與主導決策 feature 所在的層（L25–L30）相符。

6. 限制與下一步

單一案例

只有一個變異（promptintel-006.m05）、一種 prompt 模式；共用的決策 feature 需要在更多 A0/A3 配對上確認，才能稱為一般性的工具呼叫 feature。

線性歸因、凍結 attention

邊是凍結 attention 與 normalisation 下的一階歸因，不是因果效果；經由 attention pattern 的影響不會以邊的形式呈現。

重建誤差

決策位置的 MLP 誤差節點很大，且在兩個條件下都推向呼叫，A0 的行為有一部分在 replacement model 之外。

涵蓋率

圖中保留約 65 萬個活躍 feature 中的 8,192 個；部分主導 feature（如 L34#145627）只有約一半的啟動量能被圖中節點解釋。

模型不一致與數值解析度

行為機率來自 bf16 greedy decoding，圖中的 logit 機率來自 replacement model，兩者略有差異；介入的 logit 以 bf16 計算，log-odds 以約 0.25 為一階，更小的差異沒有意義。

下一步

在第 21–29 層做 head 層級的 attention patching，找出承載記憶差異的 head，並比較它們在兩條件下對記憶段落與 harness [] 範例的注意力。

模型：Qwen/Qwen3-8B（bf16）、Ollama chat template、/no_think；Replacement model：mwhanna/qwen3-8b-transcoders、circuit-tracer、TransformerLens；max_feature_nodes 8192。完整設定與互動圖表見 A0 vs A3 Attribution Graph Analysis。
