一句話理解整個專題

研究對象是會載入第三方 Markdown 技能檔（SKILL.md）、具備持久記憶與工具呼叫能力的 LLM Agent。這三項能力結合起來，讓攻擊者有機會透過一份被汙染的文件，在之後的回合才觸發延遲的多步攻擊。本專題提出一套可重現、完全去武器化的 fuzzing 方法來量測這種攻擊，並評估 AI 防禦。

攻擊拆成三個可量測的階段

F5 惡意技能供應鏈

Agent 載入含有注入內容的 SKILL.md。

→
F2 記憶污染

Agent 在第一回合把注入內容寫進記憶。

→
F3 工具濫用

第二回合使用者只提出一般問題，Agent 卻依記憶呼叫被注入的工具。

既有研究（InjecAgent）只涵蓋單回合的工具誤用；本專題補上 F5 與 F2 兩個階段，不只測「當場照做」，也測「寫進記憶、之後才發作」。

主要發現

強模型在硬化 prompt 下幾乎攻不破

GPT-5.6-sol 在 strict 設定下，兩批各 360 筆的 F2、F3、端到端都是 0。但這是加了防護 prompt 的結果，不能代表模型本身就安全。

小模型上跨回合攻擊確實存在

harness v2 下 Qwen2.5-7B 完成整條攻擊鏈 6/360（1.7%），Qwen3-8B 為 1/360（0.3%），全部來自 authority_claim 變異算子。

瓶頸是「把指令寫進記憶」

指令一旦進了記憶，回合 2 有 89% 照做，而且回覆使用者時不會提到用了工具。

記憶措辭決定成敗

只把記憶改成描述語氣，Qwen3 的照做率就從 10/10 降到 0/10（p = 1.1×10⁻⁵）。
